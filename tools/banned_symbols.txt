# Symbols the shipped binary (//dcfs:main_static) must not reference
# (plan step 26.8; format in banned_symbols.py). Each ban names the rule it
# enforces.

# "No paths after startup": nothing resolves, walks or globs a path name
# once the daemon runs; everything goes through file descriptors.
ban realpath | no paths after startup
ban _ZN4dcfs8syscalls8realpath* | no paths after startup (the syscalls::realpath wrapper)
ban getcwd | no paths after startup
ban get_current_dir_name | no paths after startup
ban _ZNSt10filesystem* | no paths after startup (std::filesystem, libstdc++)
ban _ZNSt3__110filesystem* | no paths after startup (std::filesystem, libc++)
ban nftw | no paths after startup
ban nftw64 | no paths after startup
ban fts_open | no paths after startup
ban fts64_open | no paths after startup
ban glob | no paths after startup
ban glob64 | no paths after startup

# "No subprocesses or plugins".
ban system | no subprocesses or plugins
ban popen | no subprocesses or plugins
ban execv* | no subprocesses or plugins
ban execl* | no subprocesses or plugins
ban posix_spawn* | no subprocesses or plugins
ban dlopen | no subprocesses or plugins

# glibc's static link warns for these (they need the shared NSS and gconv
# modules at run time); lld ignores .gnu.warning, so the list does it.
ban getaddrinfo | static glibc loads NSS modules at run time
ban getpw* | static glibc loads NSS modules at run time
ban getgrnam* | static glibc loads NSS modules at run time
ban getgrgid* | static glibc loads NSS modules at run time
ban getgrent* | static glibc loads NSS modules at run time
ban iconv_open | static glibc loads gconv modules at run time

# Single-threaded by design: allow exactly one when the notifier thread
# arrives (today: none in our code).
ban pthread_create | single-threaded by design (one allowed when the notifier thread arrives)

# Production never reads the time except through Context::clock (an
# absl::Clock: the real one in production, a SimulatedClock in the tests;
# step 26.10): the sync interval and relatime are the only time-based
# decisions. The syscalls::clock_gettime wrapper stays for the tests, and is
# banned as a reference of the shipped objects like the libc calls.
ban clock_gettime | the time comes from Context::clock (step 26.10)
ban gettimeofday | the time comes from Context::clock (step 26.10)
ban time | the time comes from Context::clock (step 26.10)
ban _ZN4dcfs8syscalls13clock_gettime* | the time comes from Context::clock (step 26.10)
# absl::Now, by its mangled name for the pinned Abseil (update with the pin).
ban _ZN4absl12lts_202608173NowEv | the time comes from Context::clock (absl::Now reads the real clock)

# "No timers" (step 15.6b; russ, 2026-10-09: "Timers are inherently brittle.
# If things are slow, the system breaks. This system should work on everything
# ranging from an idle 256 core supercomputer to a 1 core raspberry pi under 40
# loadavg."): dcfs waits for another process or the kernel on the event (a
# pidfd, a lock, a read that blocks) and lets the caller cancel. A timeout is
# permitted only where the thing waited for cannot signal; each use below names
# it. docs/style.md, "No timers".
ban sleep | no timers: wait on the event
ban usleep | no timers: wait on the event
ban nanosleep | no timers: wait on the event
ban clock_nanosleep | no timers: wait on the event
ban _ZN4dcfs8syscalls9nanosleep* | no timers: wait on the event (the syscalls::nanosleep wrapper)
ban alarm | no timers: wait on the event
ban timer_create | no timers: wait on the event
ban timerfd_create | no timers: wait on the event
ban setitimer | no timers: wait on the event
ban pthread_cond_timedwait | no timers: wait on the event
ban pthread_cond_clockwait | no timers: wait on the event
ban sem_timedwait | no timers: wait on the event
ban sem_clockwait | no timers: wait on the event
ban AbslInternalSleepFor* | no timers: wait on the event (absl::SleepFor)
ban _ZN4absl*WithTimeout* | no timers: wait on the event (absl::Mutex and absl::CondVar waits with a timeout)
ban _ZN4absl*WithDeadline* | no timers: wait on the event (absl::Mutex and absl::CondVar waits with a deadline)
ban sqlite3_busy_timeout | no timers: a lock that is not free is an immediate, clear error (one daemon owns a cache database)
ban sqlite3_busy_handler | no timers: a lock that is not free is an immediate, clear error (one daemon owns a cache database)

# Statuses carry the message.
ban strerror | statuses carry the message (use ErrnoToStatus)
ban strerror_r | statuses carry the message (use ErrnoToStatus)
ban __xpg_strerror_r | statuses carry the message (use ErrnoToStatus)

# Abseil only (absl::StrFormat, absl::StrCat, LOG).
ban printf | Abseil only
ban fprintf | Abseil only
ban sprintf | Abseil only
ban snprintf | Abseil only
ban puts | Abseil only
ban __printf_chk | Abseil only
ban __fprintf_chk | Abseil only
ban __sprintf_chk | Abseil only
ban __snprintf_chk | Abseil only

# ---- Allowed uses ------------------------------------------------------
# Each line names an origin (an object path glob), a symbol and why that
# use does not break the rule. //tools:banned_symbols_test fails on an allow
# line that matches nothing, so this list only shrinks by deleting lines.

# First party, startup only: "no paths after startup" permits these.
allow dcfs/_objs/syscalls/* realpath | the syscalls::realpath wrapper itself; its callers are gated by the wrapper's own ban
allow dcfs/_objs/absolute_paths/* _ZN4dcfs8syscalls8realpath* | startup only: the wrapper makes SOURCE, MOUNTPOINT and the cache database absolute before it detaches (it has no working directory after)
allow dcfs/_objs/remount/* _ZN4dcfs8syscalls8realpath* | startup only: the wrapper's remount canonicalizes MOUNTPOINT once before acting on it
allow dcfs/_objs/syscalls_process/* execv | the capture helper of the mount.dcfs wrapper runs mount(8) (step 15.2), and the umount.fuse.dcfs helper runs `umount -i` (step 15.6b): the callers are the wrapper and helper entry points, never the daemon; nothing else execs
allow dcfs/_objs/umount_helper/* _ZN4dcfs8syscalls8realpath* | startup only: the daemon canonicalizes MOUNTPOINT once, before the mount, to find its mountinfo line (CanonicalMountpoint); the umount.fuse helper resolves its target once, as the mountinfo line of a mount it was not given a canonical path for
allow dcfs/_objs/mounts_below/* _ZN4dcfs8syscalls8realpath* | startup only: mounts_below.cc canonicalizes --source once, from main.cc (MountsBelow), before the mount

# Abseil: formatting and diagnostics internals.
allow abseil-cpp+/* clock_gettime | Abseil's own clock, mutex timeouts and sysinfo
allow abseil-cpp+/* _ZN4absl12lts_202608173NowEv | Abseil's own logging timestamps, Mutex and sampling
allow abseil-cpp+/absl/base/_objs/base/sysinfo* nanosleep | Abseil's own MeasureTscFrequencyWithSleep, which calibrates the CPU's cycle counter against the clock once (GetNominalCPUFrequency, for absl::base_internal::CycleClock, which Abseil's Mutex and logging timestamps use): a measurement, not a wait for anything; dcfs calls none
allow abseil-cpp+/absl/time/_objs/time/clock* nanosleep | absl::SleepFor itself (AbslInternalSleepFor); dcfs never calls it (the ban above)
allow abseil-cpp+/absl/synchronization/_objs/synchronization/* pthread_cond_timedwait | Abseil's own Mutex/CondVar waiters (absl::Mutex, absl::CondVar, absl::Notification) implement their timed waits with it; dcfs, single-threaded, calls none (the WithTimeout and WithDeadline bans)
allow abseil-cpp+/absl/synchronization/_objs/synchronization/* pthread_cond_clockwait | same: Abseil's Mutex/CondVar waiters
allow abseil-cpp+/absl/synchronization/_objs/synchronization/* sem_timedwait | same: Abseil's Mutex/CondVar waiters
allow abseil-cpp+/absl/synchronization/_objs/synchronization/* sem_clockwait | same: Abseil's Mutex/CondVar waiters
allow abseil-cpp+/absl/synchronization/_objs/synchronization/* AbslInternalSleepFor* | Abseil's Mutex spin-lock back-off (a contended absl::Mutex cannot signal); dcfs is single-threaded, so nothing contends
allow abseil-cpp+/absl/time/_objs/clock_interface/* AbslInternalSleepFor* | absl::Clock::SleepFor of the real clock; dcfs never calls it (the ban above)
allow abseil-cpp+/* snprintf | Abseil's own number, float, stack-trace and Mutex-debug formatting
allow abseil-cpp+/* strerror_r | absl::base_internal::StrError
allow abseil-cpp+/absl/strings/_objs/str_format_internal/parser* fprintf | the `#if defined(__clang__)` debug dump in str_format/constexpr_parser.h (clang only)

# SQLite: the amalgamation's unix VFS and extension loader.
